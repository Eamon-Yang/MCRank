# Third-party components

The Windows distribution bundles Python and packages including NumPy, pandas,
Matplotlib, PySide6 / Qt, Shiboken, openpyxl, Pillow, python-dateutil and their
dependencies. Their own licenses continue to apply. Package license files are
included in the bundled package metadata where provided by the build hooks.
PySide6 / Qt are used as shared libraries, without modifying their source.

For redistribution, consult the license files and official upstream licensing
terms for each dependency. This project does not claim ownership of those
components. Windows Segoe UI is loaded from the operating system and
is not copied into the project.
